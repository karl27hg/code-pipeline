사용법

Python 코드를 단계별 박스로 나눠 파이프라인 이미지로 만듭니다.

기본 순서

  1. 예제 코드를 왼쪽 편집창에 붙여넣습니다.
  2. 한 단계로 묶을 줄을 선택하고 Ctrl+/를 누른 뒤 설명을 적습니다.
  3. 위쪽 칸에 파이프라인 제목을 적습니다.
  4. 이미지 복사를 누르고 Discord에서 Ctrl+V 합니다.

단계 표시 규칙

  • # %% 설명 줄에서 새 박스가 시작됩니다. 직접 입력해도 됩니다.
  • 바로 이어진 # %% 줄은 둘째 줄 설명(회색 글씨)이 됩니다.
  • 내용 없는 # %% 줄은 앞 박스가 끝나는 곳을 표시합니다.

단축키

Ctrl+/선택한 줄(없으면 현재 줄)을 블록 → 주석 → 원래 코드 순으로 전환
Tab공백 4칸 들여쓰기
Ctrl+Z되돌리기
Ctrl+SMD 저장

Mac에서는 Ctrl 대신 ⌘(Cmd)를 누릅니다.

저장과 불러오기

PY 저장# %% 표시가 든 원본 코드. 그대로 실행되고, 다시 열어 이어서 편집할 수 있습니다.
MD 저장제목·설명·코드블록으로 정리된 문서
PNG 저장파이프라인 이미지 파일
열기.py/.md 파일 불러오기. 파일을 창에 끌어다 놓아도 됩니다.
비우기 / 예제코드 칸 위의 버튼. 작성 중인 내용이 있으면 바꾸기 전에 확인합니다.

작성 중인 내용은 이 브라우저에 자동으로 보관됩니다.
